# Ashutosh Singh — Portfolio

A fast, responsive static personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. No build step or dependency installation is required.

## Before publishing

1. Replace `assets/resume/README.txt` with a real PDF résumé and update its link in `index.html`.
2. Add a personal photo by replacing the visual placeholder in the hero section.
3. Change the project placeholders to actual project repository and live-demo URLs.
4. Connect the contact form to Formspree, Netlify Forms, or another form service for reliable web submissions (it currently opens the visitor's email app).

## Deployment

Upload the contents of this folder to GitHub Pages, Netlify, or Vercel. As a static site, it needs no server configuration.
